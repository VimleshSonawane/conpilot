ConPilot: an AI co-pilot for construction project controls

A browser tool that takes the schedule a project manager already has, finds the data errors, measures cost and schedule performance, and answers questions with AI. I ran it as a two-sprint Scrum project, from MVP to a full project-controls product.

The problem

Overruns are visible in the data long before anyone acts on them

Errors are found late

Duplicate WBS codes, impossible dates and broken links are caught by hand, often after the report has gone out.

ConPilot checks every row on upload and suggests a fix for each problem.

Reports look backward

Status reports describe last month. They don't say where cost and finish date will land.

Earned value, an earned-schedule finish forecast and what-if sliders.

Generic AI doesn't know the job

Pasting a schedule into a chatbot gives answers that ignore the project's numbers.

An assistant that uses only the project's data and cites WBS codes.

Product decisions

Choices that shaped the product

The file never leaves the browser

Schedules carry commercial data. Parsing happens on the user's device, and only a compact summary goes to the AI when someone asks a question.

Security in the MVP, not later

The API key stays on the server. Requests are checked for origin, size and shape, rate-limited per IP, and can be gated by an access code compared in constant time.

AI grounded in the project's numbers

The system prompt is fixed on the server: answer only from the project data, cite WBS codes, treat spreadsheet text as untrusted, and decline off-topic requests.

Work with files people already have

Column mapping accepts exports from Smartsheet, MS Project, Primavera and AutoCAD tables, so there's no new tool to adopt before seeing value.

Lessons & next sprint

What I'd do differently

  • One source of truthSprint 2 went only into the single-file build, so the deployable folder fell behind. Next sprint: merge the two front ends.
  • Small commitsUse one commit or pull request per story with a descriptive message, so every change traces back to the backlog.
  • Definition of doneAdd automated tests for the earned-value and critical-path maths, and confirm the deployment, environment variables and domain are live.
  • ScaleMove the per-instance rate limit to shared storage and self-host the libraries so the security policy can drop its CDN hosts.
